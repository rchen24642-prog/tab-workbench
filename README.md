# 标签页工作台（Tab Workbench）

一个运行在 Chrome 右侧边栏中的标签页工作台。它与当前浏览器窗口实时同步，可以为标签页设置更容易理解的名称和备注、管理 Chrome 原生分组，并把暂时不用的页面放入“稍后再看”。

> 当前版本：`0.1.0` · Chrome Manifest V3

## 为什么做这个扩展

工作或学习时，我们经常同时打开很多页面。网页原始标题不一定能说明用途，任务中断后也很难记住上次进行到哪里。标签页工作台让每个正在使用的页面都能携带清晰的名称、备注和分组信息，同时保持与 Chrome 标签页实时同步。

## 功能

- 管理当前窗口或全部 Chrome 窗口
- 实时同步标签页的新建、关闭、移动、切换和页面变化
- 设置自定义名称；未设置时显示网页原始标题
- 按具体 URL 保存名称和备注
- 一键复制完整 URL
- 搜索名称、原始标题、URL、域名、备注和分组
- 创建和编辑 Chrome 原生标签页组
- 修改分组名称、颜色和折叠状态
- 拖动标签页快速移动到其他分组或“未分组”
- 将单个标签页或整个分组放入“稍后再看”
- 恢复、批量恢复或删除稍后再看记录
- 手动关闭单个标签页时清理对应数据
- Chrome 窗口整体退出时保留数据，以便恢复会话

## 本地加载

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `tab-workbench` 目录。
6. 点击浏览器工具栏中的“标签页工作台”图标打开侧边栏。

扩展目前不需要安装依赖，也不需要构建，加载源代码目录即可使用。

## 使用方式

### 修改名称与备注

把鼠标移到标签页条目上，点击编辑按钮。自定义名称和备注只绑定当前 URL；页面跳转到不同 URL 后会使用另一份独立数据。

### 快速调整分组

直接把标签页条目拖到目标分组。拖到“未分组”区域可以将标签页移出原分组。分组变化会同步到 Chrome 原生标签页组。

### 稍后再看

点击标签页旁边的“稍后再看”按钮后，扩展会先保存 URL、名称、备注和分组信息，再关闭真实标签页。之后可以从“稍后再看”列表恢复。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取标题、URL 和图标，并切换、移动、关闭或恢复标签页 |
| `tabGroups` | 读取和修改 Chrome 原生标签页分组 |
| `storage` | 在本机保存自定义名称、备注和稍后再看记录 |
| `sidePanel` | 在 Chrome 右侧边栏中展示工作台 |

所有数据都保存在 Chrome 本地扩展存储中，当前版本不包含服务器、账号系统或远程同步。

## 开发

修改代码后，在 `chrome://extensions/` 中找到“标签页工作台”，点击刷新按钮，然后重新打开侧边栏即可验证。

静态检查：

```bash
node --check background.js
node --check sidepanel.js
python3 -m json.tool manifest.json
```

## 当前限制

- 第一版只修改侧边栏中的自定义名称，不修改网页顶部标签标题。
- 恢复浏览器会话时，会按 URL 尝试关联上次保存的数据；重复打开完全相同 URL 时优先匹配第一条可用记录。
